# Ireland's Electricity Grid — TPSA Hackathon 2026

Working folder for the TPSA Hackathon, **7–11 September 2026**, TCD E3 Learning Foundry.

**The brief:** build models and optimise decision-making on Ireland's high-voltage
network, *with the goal of reducing the amount of wind energy wasted every year.*

---

## The problem in four lines

Ireland generates more wind power than its grid can always absorb. When that
happens, EirGrid instructs wind farms to reduce output — **dispatch-down**. In
2025 that was **11.3% of available wind in the Republic**: 4.7% *curtailment*
(system-wide limits) and 6.6% *constraint* (local network bottlenecks). Every
wasted MWh is near-zero-cost clean energy, usually replaced by gas.

## How every folder is laid out

**Learn one folder and you know them all.** Each content folder has the same
three subfolders:

```
0X-name/
   README.md         <- what this folder is. Always read first
   data/             <- downloaded from someone else. Never edited by us
   scripts/          <- code we wrote
   script-output/    <- what those scripts produced. Safe to delete and rebuild
```

Two exceptions, both obvious: `07-figures/` uses `charts/` instead of
`script-output/` (they are pictures, not tables), and `05-workshops/` splits by
topic into `graph-theory/` and `mcmc/`.

**The rule this encodes:** anything in `data/` is other people's work and must
not be modified. Anything in `script-output/` can be deleted at any time and
regenerated by running the matching script. If you are ever unsure whether a
file is precious, that is where to look.

File names describe contents, not abbreviations —
`dispatch-down-by-reason-monthly.csv`, not `dd.csv`. Where a file covers one
period, the period is in the name: `wind-speed-100m-2025-01.npy`.

## Running the code

Python 3.14 with `pypsa`, `highspy`, `openpyxl`, `pdfplumber`, `pyproj` installed
globally. Four scripts, each runnable from any working directory:

```bash
python 03-network/scripts/parse_wdt.py             # PDF -> constraint-group table
python 03-network/scripts/build_join.py            # join farms, stations, groups, model
python 03-network/scripts/explore_timeseries.py    # assess the model's ts_* sheets
python 02-curtailment/scripts/extract_dd.py        # dispatch-down reason codes -> CSV
python 02-curtailment/scripts/extract_system.py    # 15-minute system state -> CSV
python 04-meteorology/scripts/farm_locations.py    # Irish Grid coords -> lat/lon
python 04-meteorology/scripts/wind_power.py        # ERA5 wind -> MW
python 04-meteorology/scripts/wind_correlation.py  # correlation vs distance
python 04-meteorology/scripts/wind_forecast.py     # 7-day forecast
python 04-meteorology/scripts/validate_against_eirgrid.py   # model vs measured
python 08-analysis/scripts/audit_join.py           # check the two group mappings agree
python 08-analysis/scripts/wind_by_bus.py          # wind onto network buses
python 08-analysis/scripts/groups_vs_weather.py    # are groups a weather artefact?
python 08-analysis/scripts/curtailment_per_farm.py # per-farm curtailment estimate
python 08-analysis/scripts/contracted_pipeline.py  # future farms vs constrained nodes
python 03-network/scripts/build_pypsa_network.py   # xlsx -> PyPSA network
python 03-network/scripts/verify_ptdf.py           # check PTDF by hand: 8/8
python 03-network/scripts/compute_effectiveness.py # farm x line effectiveness
python 08-analysis/scripts/groups_vs_effectiveness.py  # do real groups cohere?
python 07-figures/scripts/make_figures.py          # rebuild all thirteen charts
```

Every script re-runs cleanly from scratch and works from any working directory.
API pulls are cached, so repeat runs cost nothing.

## What we have found

**The farm-to-constraint-group mapping exists.** Both briefing documents call it
a confirmed public gap. It is unpublished by EirGrid — but the Nayer network
model reconstructs it (`prorata_groups`, all 294 generators, overlapping
membership explicit). This is a ground truth to validate against, and its holes
are a contribution. See [01-brief/TODO.md](01-brief/TODO.md) §1.

**Irish wind barely decorrelates.** Fitted decorrelation length **460 km** —
longer than the island. Farms 200–400 km apart still correlate at 0.55. When
it's windy in Ireland it's windy nearly everywhere, so curtailment events are
national and near-simultaneous, and **siting wind farms further apart cannot fix
it.** That is why the binding constraints are network topology and minimum
conventional generation, not weather diversity.

## Conventions

- **Downloaded files keep their published filenames**, version numbers included
  (`DD-Summary-Report-V21.xlsx`). This keeps provenance traceable and makes them
  easy to re-download or check for a newer edition.
- **Files we generated use `snake_case`** (`constraint-groups-to-stations.csv`).
- Every folder README ends with a **References** section giving the source,
  licence and retrieval date for every file in it.
- Claims in the briefing documents carry provenance tags: `[EMAIL]`,
  `[ORGANISER]`, `[VERIFIED <date>]`, `[MINE]`, `[AI-UNVERIFIED]`.
